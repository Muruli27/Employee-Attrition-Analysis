# Dyashin Employee Attrition Analysis 📊

## 📌 Project Overview

The **Dyashin Employee Attrition Analysis** project focuses on analyzing employee attrition using Python, Pandas, Matplotlib, Seaborn, and data visualization techniques.

The main objective is to understand employee turnover patterns and identify factors that may influence employees to leave an organization. The project uses exploratory data analysis (EDA) and multiple visualizations to present meaningful insights that can support better HR decision-making.

## 🎯 Objectives

- Analyze employee attrition patterns.
- Understand attrition across departments, gender, job roles, and work locations.
- Examine the relationship between attrition and job level.
- Compare average monthly income and job satisfaction based on attrition status.
- Analyze attrition in relation to overtime and years at the company.
- Visualize employee attrition reasons.
- Present findings through clear and easy-to-understand charts.

## 🛠️ Technologies Used

- **Python**: Data analysis and programming.
- **Pandas**: Data manipulation and analysis.
- **NumPy**: Numerical operations.
- **Matplotlib**: Data visualization.
- **Seaborn**: Statistical data visualization.
- **Jupyter Notebook**: Interactive development and analysis.

## 🔍 Key Areas of Analysis

### 1. Department and Job Role Analysis
Examines how employee attrition differs across departments and job roles.

### 2. Employee Demographics
Analyzes attrition patterns by gender and work location.

### 3. Income and Job Satisfaction
Compares average monthly income and job satisfaction between employees who left and those who stayed.

### 4. Job Level and Experience
Studies attrition rates across job levels and years spent at the company.

### 5. Overtime and Attrition Reasons
Explores attrition patterns based on overtime status and the recorded reasons for leaving.

## ⚙️ Installation and Setup

### Prerequisites

Install Python and Jupyter Notebook on your system.

### Step 1: Clone the Repository

```bash
git clone <your-github-repository-url>
```

### Step 2: Navigate to the Project Folder

```bash
cd Dyashin-Employee-Attrition-Analysis
```

### Step 3: Install the Required Libraries

```bash
pip install pandas numpy matplotlib seaborn openpyxl jupyter
```

### Step 4: Open Jupyter Notebook

```bash
jupyter notebook
```

### Step 5: Run the Project

Open `Dyshine_Attrition_Simple_Visualizations.ipynb` and execute the cells in order.

Ensure that the Excel dataset is available in the working directory and that its filename matches the one used in the notebook.
